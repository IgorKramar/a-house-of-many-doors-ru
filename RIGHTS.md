# Авторство и права

Это неофициальная русская локализация A House of Many Doors. Игра, её тексты, изображения, персонажи и другие исходные материалы принадлежат соответствующим правообладателям. Проект не заявляет об официальном одобрении.

Перевод и инструменты подготовлены в проекте Игоря Крамаря с помощью Codex. Universal Modder 0.2.0 использовался для исследования маршрута, работы с ресурсами и технических заметок. UndertaleModTool/UndertaleModCli — сторонний инструмент; его бинарные файлы не включены.

Cormorant Garamond используется для типографики по SIL Open Font License. Шрифтовой файл в этом снимке отсутствует; при его использовании необходимо соблюдать условия исходной лицензии. Georgia используется только локально из Windows и здесь не распространяется.

Баннер SVG создан для этого репозитория средствами векторной разметки и не содержит изображений из игры. Пробные изображения, созданные генератором и забракованные в процессе, не использованы.

Общая лицензия на весь репозиторий пока не выбрана. Публичная доступность не отменяет права авторов и не означает разрешение на любое повторное распространение. Условия сторонних материалов сохраняются отдельно. Будущий пользовательский выпуск планируется в виде патча, требующего собственной копии игры.
